# Dimension Tint

Серверный мод для Fabric, который окрашивает ники игроков в TAB-листе в зависимости от текущего измерения.

## О моде

**DimensionTint** — это лёгкий серверный мод, который динамически меняет цвет ников в списке игроков (TAB) в соответствии с измерением, в котором находится локальный игрок. Больше не нужно гадать, в каком мире ты находишься — просто открой TAB и посмотри на цвет.

Мод полностью настраивается через простой `.properties`-файл и поддерживает как ванильные, так и модовые измерения.

## Возможности

- **Динамическая окраска ников** в TAB-листе
- **Поддержка всех измерений** — Верхний мир, Нижний мир, Край и любые модовые
- **Гибкая конфигурация** через `.properties`-файл
- **Цвета в формате майнкрафта** (`&a`, `&c`, `&5`)
- **Автоматическая генерация конфига** при первом запуске


## ⚙️ Конфигурация

Файл конфига находится по пути:
```
.minecraft/config/dimensiontintconfig.properties
```

### Формат записи

```properties
<dimension_id>=<color>
```

- `<dimension_id>` — полный ID измерения, например `minecraft:overworld`
- `&<код_цвета>` — стандартный код цвета Minecraft (`&0`–`&f`)

### Пример конфига

```properties
minecraft:overworld=&a
minecraft:the_nether=&c
minecraft:the_end=&5

twilightforest:twilight_forest=&9
magnatour:ore_continent=&f
```

### Добавление модового измерения

Если у тебя установлен мод, добавляющий новое измерение:

1. Открой конфиг `dimensiontintconfig.properties`
2. Добавь новую строку с ID измерения и желаемым цветом
3. Сохрани файл и перезапусти игру

**Как узнать ID измерения?**
- Открой TAB или F3 и посмотри название измерения
- Или загляни в исходники мода / его документацию
